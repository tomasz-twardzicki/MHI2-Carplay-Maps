# v1.6.6-e installation, recovery and car checks

Use the complete SD ZIP on the exact supported MU1367 K4525/P4521 firmware. Keep the whole Custom/Toolbox tree and recovery snapshots. Do not copy individual payloads onto a live installation.

1. Disconnect the iPhone/USB adapter and fully reboot. Extract the entire ZIP to a clean SD root and refresh both GEM menus and scripts.
2. Run the included **release installer** / RUN_INSTALL.sh. From a tested 790 overlay, it first restores that child's saved parent and asks for a full reboot. From another recognized wireless version, it restores that layer next. Reboot fully and repeat the same installer after every request until v1.6.6-e reports installed. v1.5.3/v1.5.4, stable v1.6.1 and the recognized experimental generations remain supported. A clean unit can install the included base and wireless layers without a separate old package.
3. **AID 790:** before connecting the phone, choose GEM → carplay-maps-vc-experimental → **790: maps + playback information + OEM touch**, then fully reboot. The base installation starts as 791; select the correct profile while the phone is disconnected. For 791, keep the base profile. Profile changes/removal may require restoring the current child, rebooting and repeating the action.
4. Fresh turn-card menu preferences are **Off**. An explicit saved menu choice is retained. The new 790 wireless profile also starts with a map-only URL; use its GEM **wireless turn card On/Off** actions to compare. Its safe-area reset is 202,16,606,344 within a 1010×376 stream, centred for both map and navigation. GEM geometry/card changes require the phone disconnected and a full reboot. Wired geometry is unchanged.
5. Keep 791 comparison tuning at 40 fps / IDR 8 / smoothing 150 ms. The tested 790 backend retains its own 30 fps request and map/video pipeline. Confirm map, OEM overlay touch, reverse return, audio, track text and artwork. Features provided by the custom 791 receiver tap are not automatically available on 790.
6. BT profile release is opt-in: **Wireless BT profile release: profiles** (or the 790 call/media preference). The phone must issue disableBluetooth, the session must be accepted and stable, the guard installed/live, the phone currently trusted, and call state known idle. Active/ringing/dialling calls defer it; retries are bounded and repeated short failures retain BT. A request is not confirmation: diagnostics report actual profile-state confirmation. Full ACL or global stack shutdown is not implemented. Use **keep** to stop further release requests; it is not a live call-transfer button.
7. Test reconnect after Wi-Fi loss, BT-only loss, explicit CarPlay disconnect, wired takeover and a later cold ignition. RC retains its OEM-held ACL scan. It waits briefly for HMI trust at boot, prefers the last accepted currently trusted phone, excludes stale candidates from fallback, cools a failed address, and allows existing native Wi-Fi Control discovery a 15-second window after unexpected accepted-session loss before BT fallback. Manual stop, wired and ignition/standby policy block outbound retries. The real vehicle must confirm latency and radio behavior.
8. Test a driving route with next/current/off road labels. Capture actual f19/f20 text and blank reasons if the dial is empty. Collect ordinary diagnostics during startup/rebase, media or call symptoms; both combined export and standalone wireless collection include the new status and histories. Private BT policy/request/last-peer files are excluded. Route, GPS and media snapshots can still contain personal information.

## Recovery

Use this SD's profile removal to restore the saved 791 parent, then fully reboot. Use **Remove wireless and restore previous layer** for managed wireless rollback. Complete OEM restore retires children and wireless layers in reverse order, preserving every requested reboot, then performs the firmware-matched forward OEM reset, including the known plaintext omonob v3.0/v3.1/v3.2 scope. Repeat after each requested reboot until complete. Recovery folders and unknown changed files are preserved. Older SD toolboxes do not recognize this release's new roots.

User preferences, including the private last successful phone hint, remain user data; they do not reactivate software after OEM restore. The hint is used only when the phone is still in the current OEM trusted list. Keep GPS forwarding off: a qualified wireless raw GNSS/UTC producer is still unavailable. No startup-freeze fix is claimed.
