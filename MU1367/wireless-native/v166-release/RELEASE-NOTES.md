Allow a bounded native Wi-Fi Control discovery window before BT fallback. Apply manual stop, wired and ignition/standby gates. No pairing database is edited.
- Preserve unused prefetched manoeuvre roads and log actual NavSD function 19/20 text, submission results and blank reasons. Separate capture-clock repair details from matching misses and PCR-lead rebases while keeping the accepted smoothing decisions.
- Retain stable ETA/arrival formatting, IDR options, working artwork and other 791 changes. Carry the later complete OEM-restore coverage, completed-reset retention, exact firmware gates and retained-layer/reboot migration into the full package.

Known limits: combined release vehicle acceptance is pending. The 790 runtime retains 30 fps and lacks the custom 791 guidance/timing/IDR/GPS extensions. Raw GNSS plus UTC, full ACL release and the main-screen startup freeze remain open. Bench tests do not establish physical radio, microphone/call routing, decoder cadence or cluster field selection. BT coexistence/reconnect work follows Apple's WWDC17 session 717: https://developer.apple.com/videos/play/wwdc2017/717/.

Validation: 12 real-controller host release groups and seven profile groups passed, including all 17 child failure/interruption sites and migration from the exact tested 790 ZIP. Separate native QNX checks cover the 45-target parent, profile selection/recovery, complete OEM reset, diagnostics and the 790 launcher/BT-wrapper contract. Import checks pass against K4525/P4521 HW50/HW70. The full fresh native SDK image remains a harness limitation after memory/boot failures; its failed evidence is retained alongside the passing host and per-layer native checks in VERIFICATION.json.
