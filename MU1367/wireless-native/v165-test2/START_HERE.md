# v1.6.5-e-test2 installation and car test

Use the complete SD ZIP for the exact supported MU1367 K4525/P4521 firmware. Keep Custom, Toolbox and recovery snapshots together. This test focuses on BT attachment and independent road-text fields.

1. Extract the whole ZIP to the SD root and run the included GEM **release installer**. From test1 or another recognized wireless layer, it restores that layer first. Perform every requested full MU reboot and run the same installer again until test2 reports installed. Supported v1.5.3/v1.5.4 and stable v1.6.1 migration paths remain included. Do not delete retained recovery roots or copy individual files over the live installation.
2. Keep **40 fps / IDR 8 / smoothing 150 ms**, GPS off, and the same paired-phone list for the first comparison. Native main-screen demand remains 30. Confirm MU/AID video, audio, native guidance, RHD layout, reverse return, track text and artwork. Media/timing binaries are unchanged from the test1 that worked in your car.
3. Establish wireless CarPlay completely, then switch only phone Bluetooth off while Wi-Fi stays on. CarPlay should remain active if the guard attaches and the accepted control/session lease stays live. Export normal diagnostics immediately. Restore Bluetooth, switch only Wi-Fi off, verify native teardown, reconnect, then test another full cold start. BT status should show installed=1, a fresh live owner, and increasing preservation/paging/resend counters where those native decisions occur. A failed attachment now logs global/libc/slot addresses and dladdr identities; do not infer success merely from the option being enabled.
4. Choose GEM → Wireless → **Dial road label: next** again after upgrading. Check the dial and middle display independently: function 20 now carries the upcoming road and function 19 the current road. Test current and off too; function 19 should remain current while off blanks function 20. Test wired as well as wireless, rerouting, stopping the route, OEM navigation takeover and exits/roundabouts in Google Maps, Apple Maps and Waze. This is a field-selection experiment: report if both visible labels still follow function 20.
5. Capture the first minute after connection and after reconnect, noting when any main-screen freeze starts/ends and whether touch/audio continue. Export standard diagnostics while the symptom is present. The existing launch/ownership traces and timing summaries remain included. No startup or reconnect-gap fix is claimed by this package; pre-acceptance stale-phone paging remains open.
6. Confirm artwork and track changes still work on both MU and AID. Retain before/after diagnostics rather than summing counters across overlapping exports. The normal base export includes wireless, BT, media, GPS-status and trace evidence; the separate GEM wireless collector remains available. Pairing stores are excluded, but route/location/media snapshots can contain personal trip or track information.

## Recovery

Use test2's **Remove wireless and restore v1.5.4 (reboot)** for its previous-layer restoration. Follow its full-reboot and installer instructions before returning to stable or another package. Use this SD's **complete OEM restore** for full managed removal, repeating after every required reboot until complete. The new root and its GPS/probe/road metadata are archived. Unknown changed controllers/files are refused or preserved. Older SD toolboxes cannot recognize this new root; retain test2 for recovery. This is not a universal uninstaller for arbitrary third-party installations.

## Limits

Factory ARM/J9 tests prove independent NavSD values, not which field the physical cluster uses for each label. Native QNX tests simulate the conflicting global lookup and exercise pinned BT decisions; actual radio/call/ignition behavior still needs car acceptance. Accepted-session suppression does not change which phone rc pages before CarPlay is established. GPS forwarding is unchanged, off by default, and still lacks a qualified wireless-only raw GNSS/UTC producer. Do not enable it expecting this package to fix location sourcing.
